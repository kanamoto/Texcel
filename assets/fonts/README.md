# Bundled grid fonts

Texcel bundles the Japanese Regular and Bold faces of Noto Sans CJK JP and
Noto Sans Mono CJK JP from the official `notofonts/noto-cjk` repository:

- `NotoSansCJKjp-Regular.otf`
- `NotoSansCJKjp-Bold.otf`
- `NotoSansMonoCJKjp-Regular.otf`
- `NotoSansMonoCJKjp-Bold.otf`

The proportional faces are from [`Sans/OTF/Japanese/`](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/Japanese); the monospace faces are
from [`Sans/Mono/OTF/Japanese/`](https://github.com/notofonts/noto-cjk/tree/main/Sans/Mono/OTF/Japanese). The monospace files came from the official
[Sans2.004/11_NotoSansMonoCJKjp.zip release archive](https://github.com/notofonts/noto-cjk/releases/download/Sans2.004/11_NotoSansMonoCJKjp.zip).
Their license is in `LICENSE-Noto-Sans-CJK.txt` (SIL Open Font License 1.1).
The bundled faces provide a fixed Japanese fallback for proportional and
monospace application text.
